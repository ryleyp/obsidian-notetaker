EA ACTIVITY TAB - USER GUIDE
=============================


WHAT IT DOES
------------
The EA Activity tab reads your Obsidian meeting notes from a date range you
choose and generates a pre-formatted activity table you can copy into
Salesforce for EA Engagement reporting. For each reportable activity it:

  - picks the correct Type and Subtype from the SFDC taxonomy
  - pulls in contact names and titles from your notes
  - writes a comment aimed at an executive reader
  - flags anything it is unsure about so you can review before copying

It does not log anything to Salesforce for you. You stay in control of the
final copy-paste.



HOW ACTIVITIES GET CLASSIFIED
-----------------------------
A few rules drive how the app sorts your notes. Knowing these up front
helps the output make sense.

EA Admins are customer-side IT administrators (at companies like Beacon Systems,
Cardinal Defense, Acme Aerospace, Delta Microsystems) who manage NI licensing and
EA logistics for their company. They are not NI employees. Meetings with
EA Admins are always treated as customer-facing, classified as either
"EA Admin Sync" or "EA Admin Onboarding" depending on context.

What gets included:
  - Customer meetings, including EA Admin syncs and governance calls
  - User group sessions and demo days
  - Internal NI sessions that produced a clear decision or outcome
  - Training planning sessions and campaign activities
  - Escalations and risk management activities
  - Case study and ROI capture sessions

What gets left out:
  - Routine emails or check-ins with no outcome
  - Duplicate rows when the same session shows up in multiple notes
  - Notes that belong to other accounts (filtered out automatically)
  - Low-value logistics with no reportable substance


STEP-BY-STEP
------------
1. Click "EA Activity" in the top navigation bar.

2. Select the account folder you want to report on using the folder picker.

3. Set your date range.
   The default is the past 3 months. You can change the start and end
   dates, or use a quarter preset (Q1, Q2, Q3, Q4) if you are reporting
   for a specific quarter.

4. Click "Scan Folder."
   The app finds all notes dated within your selected range and shows a
   summary, for example: "Found 11 notes, 8 flagged as reportable."
   Review this to make sure nothing important was missed.

5. Review the scrub panel (only shows when needed).
   If the scan finds lines that mention other account names, those lines
   are flagged here so they do not leak into this account's report.
   Check any flagged line you actually want to keep, then continue.

6. Click "Generate EA Activity Report."
   Rows stream in live as Claude reads through your notes. Any row the
   app is unsure about (for example, a session that could be either a
   demo or a user group) is marked with a review flag.

7. Review and edit.
   Rows badged "from note" were taken straight from the reviewed SFDC
   Activity Entry already in that note — no model touched them. Rows
   badged "generated" were classified by Claude from notes that had no
   entry (handwritten or older notes). You can edit any cell directly,
   especially the Comments column. To redo a single row without
   rerunning everything, click the ↻ button on that row.

   Tick "Filed" once you've logged a row in Salesforce. Filed rows are
   remembered and greyed out the next time the same period is generated,
   and the most recent ones are shown to Claude as examples so its
   classification matches yours.

   Choose Quick, Second opinion, Compare both, or Review flagged before generating.
   The second provider can review both existing SFDC entries and newly generated
   activities for clearer wording, supported outcomes, and correct classification.
   Review the before/after proposals and apply a complete proposal, one activity,
   or one field. You can also run an independent alternative on a finished report.
   Dates, agreements, source references, and Filed status are preserved.
   The improvement pass uses the selected alternative OpenAI or Claude model and your privacy filters.
   Add your OpenAI API key in Settings first. The model picker includes GPT-6 Astra,
   GPT-5.6 Sol, GPT-5.6 Terra, and GPT-5.6 Luna, with input/output rates shown.
   Without loaded source notes it can improve wording and classification
   using the current rows, but cannot verify facts against the sources.
   Applying edits enables Save to Obsidian again.


8. When finished, click "Copy" to copy the Markdown table, or
   "Save to Obsidian" to write it as a file in your vault.


WHAT YOU GET
------------
A table with one row per reportable activity:

  | Filed | Status | Event Date | Improved Title | Title | Type | Subtype | EA/EP | Source Note | Comments |

  - Filed            [x] once the activity is logged in Salesforce; the next
                     run of the same folder honors it
  - Status           Completed (default), Planned, or Canceled
  - Event Date       the date in the source note's title, which always wins
                     over any date the AI picked out of the meeting text
  - Improved Title   the Salesforce-ready title that gets filed. Generated
                     rows get one with the report; harvested entries carry
                     the note's Recommended Title, and any row still
                     missing one (older notes, reopened reports) is filled
                     in automatically after the table loads
  - Title            the engagement as the source names it (the meeting or
                     note title); kept beside the improved title so nothing
                     is lost
  - Type             one of the 6 SFDC EA Engagement Types
  - Subtype          specific subtype within that Type
  - EA/EP            the agreement number(s) the activity relates to
  - Source Note      the note or voice memo the row came from
  - Comments         up to 800 characters (the Salesforce field limit), in
                     the same plain voice as the SFDC entries in your notes

Example rows:

  | Beacon Systems | 2026-04-12 | Q2 Licensing Governance Sync | Strategic Relationship Management | EA Admin Sync | Sync with Dana Voss, IT Admin Lead, to lock down true-up ownership ahead of the Q3 renewal. Defined the handoff so the CSM owns the process post-deployment, reducing renewal risk. |
  | Beacon Systems | 2026-05-03 | SystemLink Adoption Demo Day | User Groups | Demo Day | Beacon Systems SystemLink Demo Day | Region: Southeast | Attendees: 22. NI-led walkthrough of new dashboard features for the test engineering team. Outcome: surfaced two expansion conversations and strong engagement from the analytics group. |


IF SOMETHING GOES WRONG
-----------------------
- Scan found zero notes: check that the date range covers when the
  meetings happened and that you picked the right account folder.
- A row looks miscategorized: edit the Type/Subtype directly, or use the
  row-level Regenerate. Rows flagged for review are the ones to check first.
- Generation stopped partway: the rows that already came through are kept.
  Click "Generate" again to finish the rest.


SAVING
------
Files are saved to your vault inside the selected account folder as:
  EA Activity Report YYYY-MM-DD.md

If a file with that name already exists for today, the app asks whether
you want to overwrite it or save a new copy. It will not overwrite
silently.
